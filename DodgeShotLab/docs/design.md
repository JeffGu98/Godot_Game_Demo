# 雷电式极简闪避射击设计文档

## 项目定位

- 工作名：Dodge Shot Lab
- 类型：端游原型，俯视角极简闪避射击
- 核心输入：玩家只控制移动，不控制开火
- 核心验证：移动躲避、聚怪、自动攻击、拾取武器包是否能自然产生紧张感和心流

## 设计判断

这个方向比“归零格”更适合验证紧张感，因为危险来自核心动作本身：玩家移动时既要躲避敌人和弹幕，又要把敌人带入自动攻击的有效区域。风险是：如果武器系统过早做复杂，玩家会把注意力放在数值和选择上，而不是移动手感。因此首版只做清晰的五类武器曲线，不做复杂词条和装备组合。

“拾取不同子弹包会切换子弹类型，子弹等级归零”会带来明确取舍，但也有风险：如果新武器 0 级太弱，玩家会倾向于只捡同一种包。首版用不同武器的场景优势来抵消这个风险，例如穿透武器适合直线敌群，脉冲武器适合被包围，轨道武器适合贴身穿缝。

## 核心循环

1. 玩家在屏幕下半区和中场之间移动。
2. 敌人从上方持续进入，部分敌人发射弹幕。
3. 玩家武器自动开火，玩家通过走位决定火力覆盖区域。
4. 武器包定期出现。
5. 拾取相同武器包：当前武器等级 +1。
6. 拾取不同武器包：切换为新武器，等级重置为 0。
7. 击杀、存活时间和连贯走位共同构成分数。
8. 死亡后保存本地排行榜。

## 玩家规则

- 初始武器：Needle，等级 0
- 初始火力：单发、射速慢
- 生命：3
- 受伤后短暂无敌，避免连续碰撞瞬间死亡
- 玩家无法主动射击，所有攻击由当前武器自动触发

## 五种子弹类型

### 1. Needle / 针弹

- 定位：默认直线输出，最容易理解
- 0 级：单发、低射速、低伤害
- 升级效果：
  - 提高射速
  - 提高伤害
  - 高等级时增加轻微穿透
- 风险：如果过强，会让其他武器没有价值

### 2. Fan / 扇形弹

- 定位：清理分散小怪
- 0 级：三向散射，单发伤害较低
- 升级效果：
  - 增加弹片数量
  - 扩大扇形角度
  - 小幅提高射速
- 风险：画面弹幕过多，需要控制子弹寿命和伤害

### 3. Pulse / 脉冲弹

- 定位：被包围时的范围清屏
- 0 级：从玩家位置扩散一次短程圆环
- 升级效果：
  - 提高扩散半径
  - 提高伤害
  - 缩短冷却
- 风险：如果冷却太短，会削弱闪避压力

### 4. Rail / 轨道束

- 定位：直线穿透，鼓励玩家把敌人拉成一列
- 0 级：窄直线穿透，冷却较慢
- 升级效果：
  - 提高宽度
  - 提高伤害
  - 缩短冷却
- 风险：需要敌人队形配合，否则体验波动较大

### 5. Orbit / 轨道弹

- 定位：贴身风险收益，强化穿缝和绕圈移动
- 0 级：一枚轨道弹围绕玩家旋转
- 升级效果：
  - 增加轨道弹数量
  - 增加旋转半径
  - 提高接触伤害
- 风险：可能鼓励玩家贴脸，需要敌人碰撞和弹幕限制过度贪心

## 敌人类型

### Wisp / 游荡体

- 生命：2
- 行为：慢速下压，轻微横向漂移
- 作用：基础压力和连杀目标

### Charger / 冲刺体

- 生命：1
- 行为：高速逼近玩家横向位置
- 作用：打断玩家固定站位

### Bulwark / 重甲体

- 生命：8
- 行为：慢速下压，体型较大
- 作用：制造火力检查和遮挡压力

### Spitter / 喷吐体

- 生命：4
- 行为：中速移动，周期性向玩家方向发射子弹
- 作用：制造弹幕缝隙

### Splitter / 分裂体

- 生命：3
- 行为：死亡后生成两个低生命小敌人
- 作用：制造范围武器和穿透武器的价值

## 武器包规则

- 武器包定时刷新，在场上向下漂移。
- 包类型从五种武器中随机选择。
- 碰到玩家即拾取。
- 同类型：当前武器等级 +1，最高等级暂定 5。
- 不同类型：切换武器，等级重置为 0。
- UI 显示当前武器、等级和最近拾取结果。

## 分数与排行榜

- 分数来源：
  - 存活时间
  - 击杀敌人
  - 高价值敌人额外分
- 死亡时保存本地排行榜。
- 排行榜保存前 5 名。
- 存储位置：Godot `user://dodge_shot_lab_scores.cfg`

## 首版待验证问题

- 玩家只控制移动是否足够有参与感。
- 自动射击是否会降低玩家对击杀的责任感。
- 切换武器等级归零是否形成策略选择，还是让玩家抗拒拾取。
- 五种武器是否真的改变走位方式。
- 敌人逼近和弹幕是否能制造可读的压力，而不是混乱。

## 下一步行动

1. 先试玩 3 到 5 局，观察平均存活时间。
2. 如果死亡主要来自不可读弹幕，降低 Spitter 数量和弹速。
3. 如果玩家只停在底部不动，提高 Charger 频率或让敌人更追踪玩家横向位置。
4. 如果玩家只想保留一种武器，调强 0 级切换武器的场景优势。
5. 如果击杀反馈不足，增加爆炸、屏幕震动和连杀奖励。
